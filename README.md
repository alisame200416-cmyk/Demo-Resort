# Demo-Resort — النسخة التجريبية المجانية

هذه النسخة مخصصة لعرض النظام لأصحاب الشاليهات.

## الخصوصية في وضع Demo
- لا تستخدم Firebase لحفظ الحجوزات أو الإعدادات أو الصور.
- جميع التعديلات تحفظ محلياً في متصفح الزائر عبر `localStorage`.
- رفع الصور في Demo يتم تحويله إلى صورة محلية مصغرة وتخزينها على الجهاز فقط.
- زر **إعادة بيانات التجربة** يمسح كل تعديلات Demo من الجهاز ويعيد البيانات الافتراضية.
- الضغط على روابط WhatsApp أو خرائط Google يفتح خدمة خارجية فقط بعد اختيار المستخدم لذلك.

## التشغيل
```bash
npm install
npm run dev
```

## البناء والنشر
```bash
npm run build
```
